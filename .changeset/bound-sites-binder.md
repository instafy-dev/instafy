Add `instafy bind`. `instafy bind serve <site> [--preview] [--detach]` serves a bound site: a static page plus `bound.json`, whose script intents run small handler scripts and stream checked records back to every open viewer (`init --starter compare|ranked|timeline|checklist|blank`, `doctor`, `try`, `command`, `confirm`). The binder is bundled into the CLI as `dist/bind`. "Ask Octo" (agent) intents are asks the page hands to Studio, which sends them as the clicker's own chat message; the binder answers them `409 ask_via_host` and reads no Instafy login. Only `serve --agent-executor`, the owner's opt-in, runs them as Octo turns on the owner's login, and only for clicks made on that machine. Handler fetches honour robots.txt (for `*` and the major AI user agents) on every redirect hop. `instafy preview open` now records the preview's viewer host suffix and Studio origin, so `bind serve --preview` answers that preview's capability host only on that exact domain, sends `frame-ancestors` for that Studio, and its pages take frame messages (Ask Octo, location, follow mode) from that Studio only. A `--public-url` link needs the viewer token, also with `--preview`.
