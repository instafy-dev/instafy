Add `instafy bind` and `instafy web`. `instafy bind serve <site> [--preview] [--detach]` serves a bound site: a static page plus `bound.json`, whose script intents run small handler scripts and stream checked records back to every open viewer (`init --starter compare|ranked|timeline|checklist|blank`, `doctor`, `try`, `command`, `confirm`). The binder is bundled into the CLI as `dist/bind`. "Ask Octo" (agent) intents are asks the page hands to Studio, which sends them as the clicker's own chat message; the binder answers them `409 ask_via_host` and reads no Instafy login. Only `serve --agent-executor`, the owner's opt-in, runs them as Octo turns on the owner's login, and only for clicks made on that machine. `instafy web cite <url>` reads one public page the polite way (it refuses sites that ban AI agents, paths robots.txt disallows and bot checks), and `instafy web handoff` re-checks research handoff files. `instafy preview open` now records the preview's viewer host suffix, so `bind serve --preview` answers that preview's capability host only on that exact domain.
