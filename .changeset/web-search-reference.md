`instafy web search --chain reference-search` asks Wikipedia's and Wikivoyage's search and Wikidata's official websites (P856) at once, with no key: the web-research skill's new `reference-search` chain, which asks every provider instead of the first that answers. `--lang` picks the wikis and the labels' language (English by default). Each result names the source that gave it and its attribution (Wikipedia and Wikivoyage: CC BY-SA 4.0; Wikidata: CC0), a Wikidata result's `source` is its item, and an official website on a link-only site is a link only. Requests carry a user agent with contact details, go one at a time to each source (at most 3 at once), and a source that answers 429 is not asked again in the turn; the chain counts its own 4 searches a turn. `--provider <id>` asks one provider of a chain. A space switches a source off with its own copy of `search-providers.json` (`"off": ["wikidata-official-site"]`); a copy can do nothing else. The provider list may now hold providers without a key, a `{lang}` host label, result links built from a template of the result's fields, literal braces and a SPARQL-escaped query, and it never uses Nominatim.
