Octo finds the page in a browser turn the way the browser skill's new "Finding a page" section says, and every Personal or Shared Browser turn carries that skill. A browser turn used to load the browser skill only when its words matched it, so a follow-up such as "Now find how to get there by tram" or a task that names an address loaded none of its rules; now such a turn loads the skill whatever its words, first of its skills, and a browser turn that resumes its chat's thread, which loads no skills and cannot read a skill file, is given the skill's "Finding a page" section again from the space's own copy. The section, which the web-research skill now points to instead of keeping its own copy (with one command that prints just that section when a research turn has not loaded the browser skill), says: open an address the person, a skill or a search result gave, a link on a page you read, or the home page of the official site the task is about, never a search engine or a guessed path; a page that says it is missing ("Are you lost?") is followed by that site's own search box or menu; after two failed pages on one site, find another source with `instafy web search` (`--chain reference-search` needs no key), or, in a turn with only browser tools, the home page of another official source; a sight, a stop, opening hours or a price comes from its own page, not a listing or a tourist-office kiosk page; anything not read on a page this turn says "not checked"; a comparison lists the models a page read names, and marks one only a search result names "not checked", never names from memory or placeholders such as "candidate 1"; and a cookie banner with a reject button is refused, so it does not cover the page the person watches. The research eval adds three browser turns (a guessed address, a search engine, a kiosk page as the source) and a turn that opens an address a search gave, and the comparison eval a turn whose only names come from a search (placeholder rows fail). No package changes.
