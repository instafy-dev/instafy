Instafy's browsers name controls and tabs by what a person sees. A control's visible label is the text it draws, without scripts, styles, hidden parts or an svg's metadata, title and definitions, so a search button drawn by an Inkscape icon reads "Pesquisa", not `Pesquisa (shown as "image/svg+xml")`; risk words still read every text inside the control. Image buttons are named by their alt text and input buttons by their value, and an unnamed control is also named by an inner element's label or title, its svg sprite's icon, or the short text right beside it ("button next to “Idioma” in the top right") before it reads "unnamed". Text that is only a media type ("image/svg+xml") is never a control's name or a tab's title, in the Shared Browser's snapshots, tab list and action log, origin's page list, the Personal Browser's tabs and Studio's tab pickers, which fall back to the site. Studio's prompt row and sheet quote only the control's name and say a risky category as its own sentence ("Octo wants to click “Delete account” on example.com. It may delete, cancel or sign out of something."); an ordinary step's "Change something" adds nothing. No package changes.
