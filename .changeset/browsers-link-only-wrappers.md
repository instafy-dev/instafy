Octo's Shared Browser and the desktop app's Personal Browser now also refuse a translator's, cache's or archive's copy of a link-only site (the web-research skill's list now names these wrappers: Google Translate's page proxy, the AMP cache, Google's page cache, the Wayback Machine, archive.today and the Jina reader proxy), on every route they already guard: opening or navigating a tab, a link, and every redirect hop. A wrapper is never refused for itself, only for its copy of a listed site. Matching is one shared module for both browsers and `instafy web read`, run against one shared table of cases, and treats case, trailing dots, ports, user info and international names alike. The Shared Browser also enforces the sites and wrappers the space's own copy of the list adds; a copy can only add, and one that is not a plain JSON file of the list is left out, reported in `status`, while the bundled list still applies. The Personal Browser enforces the bundled list. Spaces with the earlier, unedited bundled copy of the list get the new one. No package changes.
