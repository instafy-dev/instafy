A site preview's card says when its site stopped as soon as Octo stops it. A server stopped with a command sends no event, so when a turn in the space ends, the latest card of each preview asks the controller for a new probe (the pane asks instead while it is on screen), and every card reads the answer. A site whose server stopped answering reads like any stopped one: "Stopped · opening restarts it" where its start command is known, and then a press on the card starts it and opens it, with no second **Start again** button on the card; "Stopped · ask Octo to start it again", with no chevron and no press, where it is not. Neither the card nor the pane names a port any more. The stopped pane says one thing, "This site is stopped." with **Start again** (or how to get it back), on a solid background with no frame behind it, so the broker's own error page no longer shows through, and no red Unavailable pill above it; the frame loads the site again once it answers. A start that fails on the machine reads "Couldn't start · Ask Octo to start it again" on the card ("Couldn't start it. Ask Octo to start it again." in the pane), never the machine's own line with its port or exit status. No package changes.
