The pinned `interactive-map` skill pack is now `instafy-dev/maps-skill-pack` v0.1.12. A place on a map shows its kind only as a plain word ("Museum", "Square", "National park") or not at all, never as a map tag such as "Board". A square that shares its name with the station next to it goes on the map as the square, under the name asked for. A place next to a station is used only when it really has that name, so the station a person asked for is never swapped for a nearby park or lock. Finding places to stay keeps a hotel among the picks when one is in range, and says there is none only when there is none. On a phone, a raised map panel shows its first places whole, its list ends just above the chat's composer instead of running on under it, and tapping its search box no longer moves the panel. The map's credits name OpenStreetMap once. No package changes.
