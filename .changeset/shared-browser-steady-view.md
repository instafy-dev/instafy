Instafy's browser stays steady while Octo works in it. On a browser whose only viewer is the controller's own lane, Octo taking control used to make the view flicker between **Reconnecting…** and **Octo has control · Take over**, ten times a second, while Studio read the approval prompt and the tab list on every flicker (thousands of requests in a few minutes). The view now stays live with the last frame and **Take over**; the browser's participant list stays connected while Studio's tab list reloads; **Reconnecting…** shows only once the picture has been gone for 1.5 s; and "Approval connection interrupted" shows only once approval reads have failed for 2 s, with failed reads backing off. The approval, tab list and action log reads, and the list of tabs shared with you, are no longer repeated when their inputs change quickly, also when the page under the approval read changes back and forth, and a pace that keeps changing still reads about once a second instead of waiting for it to settle. No package changes.
