Review fixes for Octo's Shared Browser tabs. A snapshot checks the page again once it has read it, so a page that moved on to a link-only site, or to another site, while it was read reports nothing instead of that site's text under the earlier address; the action feed names only the site of a link-only page. The step guard watches the tab's own document, so an ordinary page that frames a link-only site (a map, a sign-in button, a captcha) loads and Octo's step no longer fails as if it had gone there. A link-only host is matched with every trailing dot removed. Take over from a tab a run is not bound to stops only a run that has started, never one of the conversation's runs still queued while another conversation's run holds the browser. No package changes.
