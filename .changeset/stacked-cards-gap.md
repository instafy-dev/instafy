On a page made from the blank starter, each block the page puts straight in its list keeps the theme's gap above it, so two cards one under the other no longer touch, while a button, a picture or a sentence with a link there keeps its own size and line. The other starters, which put one block there, look as they did, and a page made before keeps its own copy of `theme.css`. `instafy runtime start` runs a Docker runtime under an init, as the runtime Compose files do, so the processes the agent's tools leave behind (git's helpers, the browser's) are reaped instead of piling up.
