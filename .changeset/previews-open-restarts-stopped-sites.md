A site preview that was stopped and closed on purpose ("stop the preview server") keeps its recorded start command: its card reads Stopped, and **Open** by someone who may change the space starts the same site again, with no Octo turn. Only a preview whose tunnel a newer one replaced cannot be woken. A stopped card that nothing can start offers no dead **Open** button and says "Stopped · ask Octo to start it again", and so does an older card whose port now serves another site. A preview pane whose site stopped while it was open asks for one new session instead of one after every refusal, which used to end in "Too many previews opened" after a single open, and a card beside its open pane reads the pane's checks instead of asking the controller again. No package changes.
