Studio's Skills panel lists the skill packs installed with the space's runtime, such as the interactive map pack, as "Included with Instafy" with their version. Their files are written into the space before every turn but never saved with it, so a cloud space's panel, which reads the saved files, did not show them although Octo used them. The runtime now names its packs in its registration capabilities (`skillPacks`), the controller passes a checked, bounded copy on each runtime status entry, and the panel shows them without a switch or uninstall, since the runtime manages them. A space's own imported copy of a pack stays one of its skills. No package changes.
