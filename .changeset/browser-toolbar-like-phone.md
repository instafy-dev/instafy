The browser toolbar is quieter, like the phone's. The control chip and **Release control** / **Take control** show only when someone else could have control: another person (or your other device) in the browser, or Octo driving it. Alone there is nothing to hand over, so neither shows, except **Take control** when control is free. A pressed control action reads "Releasing…" until the browser answers, and says why nothing changed ("The browser didn't answer. Try again." or "Not connected to the browser. Try again in a moment.") instead of doing nothing. While the browser opens, its centered "Opening Instafy's browser…" is the one loading signal: the status pill's **Starting…** is for screen readers only. Enter in the address bar goes, so the wide toolbar has no **Go** button (the phone's address editor keeps one). Where the browser runs (**This device** or **Workspace**, the current one checked) moved from the toolbar into the browser's Options menu under "Run browser on", for both the Shared and the Personal Browser. A wide toolbar now reads Back, Forward, Reload, the address, Send page to Octo, the participants, Options and Expand. No package changes.
