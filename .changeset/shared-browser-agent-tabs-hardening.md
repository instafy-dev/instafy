Octo's tabs in the Shared Browser are hardened. A site on the web-research skill's link-only list is never opened or read by Octo in any tab, the page the person chose included: navigating there, following a link, form or key that leads there, and a redirect one of Octo's steps causes are all stopped before any prompt, and on a page that is on such a site every step is refused with a pointer to **Send page to Octo**; without the list Octo does nothing. When Octo closes one of its tabs the run's page or another of its tabs comes to the front, never a person's tab, and **Take over** stays available whichever tab is on screen while Octo holds the browser. Each of Octo's tabs keeps one number for its lifetime, and prompts, `list_tabs` and Studio all call it "Octo's tab 2". The chat's page strip badges Octo's tabs from the browser's own page list, so a run from another conversation on the same machine is badged too. A window a page in Octo's tab opens by itself is closed as it appears and before the next step. Tabs left open by a run that ended without a confirmed shutdown, or that the browser did not close, stay badged as Octo's and are closed at the next confirmed shutdown, runtime start or browser start, unless a person keeps them. No package changes.
