Instafy's Shared Browser asks less and loses no approval. A plain navigation asks at most once: the site's prompt names the exact page it will load (host and path, in Studio's card and sheet) and covers that navigation, and a site already approved in a tab opens its pages there without asking; a risky address still asks for the step itself. `open_tab` asks once, for the site in the new tab. Let AI continue, after a take-over or a manual step, keeps the approvals of the run it continues on the same page for the same person (runtime-agent checks it is the last run that held the browser, ended less than ten minutes ago), and its message no longer says the person finished a step they may not have taken. A declined site stays closed for the run without another prompt and Octo takes another route that fits the request or asks; declining a second site, or a step, ends the run as before. The browser cards say "A browser session is already running" for a browser session machine that is restarting or late, instead of offering a second machine. Opening the browser, or Try again, on a browser session machine that stopped answering no longer connects to its silent origin and gives up after two minutes: Studio waits until the machine answers again, for up to ten minutes as for the space's own machine, says "Still starting this space's machine…" after a minute, asks the controller for the machine again once it has been silent past its idle time (which replaces that generation), and says at once when the machine has stopped with nothing starting it. No package changes.
