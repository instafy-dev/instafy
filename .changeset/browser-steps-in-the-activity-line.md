A Shared Browser step now says what it did and on which site in the turn's activity line: "Searching visitlisboa.com…" while it runs, then "Opened carris.pt, searched visitlisboa.com, read 2 pages". Each step's result carries `activity: {step, url, approval}` from the browser's own state (never page text), and runtime-agent keeps only the step's kind, the address's host, a 16-character key of the address and how the step was allowed: `once` only when it waited on a prompt the person allowed, `routine` or `free` when it went without one, `denied` or `expired` from its consent code. Pages opened and read count by distinct page, only steps that succeeded count as opened, read or searched (a step the person said no to, left unanswered or that failed never does), a group after one on the same site drops its trailing " on {host}", and an international site shows in its own script when its letters are all of one script. Steps before a site is known, and the Personal Browser's steps, still say "used the browser". No package changes.
