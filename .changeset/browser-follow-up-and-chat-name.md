A follow-up in a browser chat goes straight to the open browser. When the chat's last turn was the person's own turn in Instafy's browser, it finished less than ten minutes ago and its tab is still open, a message from the chat composer now runs there as a browser turn, in that tab, naming the run it continues so the sites already allowed do not ask again. Before, it started an ordinary turn that only sent another "Continue in Instafy's browser" card, which needed a second press and a second approval. A card that was continued now reads a plain "Opened", and a card a newer card followed no longer offers its button, so two live cards never stack up. The chat's record of a continuation says "Opened Instafy's browser for …" after the person's own press, and names Octo only when Studio opened the browser by itself. A chat whose first prompt opens a site ("Open www.example.com and find …") is named from that prompt like every other chat: a link inside a sentence now leaves the name of its site in the title (never its path, query, port, sign-in, an address or a local-only name), where before the whole title was dropped and the chat stayed "New chat". No package changes.
