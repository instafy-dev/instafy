The compare starter says what is still missing itself, under the headline and on every screen, from its cells ("Still missing for Option B and Option C: Weight (checked 17 Oct on maker.com ↗), Price"), so a lede written before a cell changed can no longer claim a value the page shows as missing; a phone's rows no longer repeat it. Each source the page links is named by its page's site ("Sources: maker.com ↗"), in the footer and in a row's Details, once per site, and so are a review's list price and an estimate's source ("list price on babygearlab.com ↗"): a source's own name could say something its link doesn't. A row's `sources` need only their `url`. `instafy bind check` now fails a source line drawn by hand (an element with the class `trust`) that links no page, and a fact with its source and no page, and names each, unless the line says "not checked" or "From what Octo knows", or only that a value is unknown; a line with something in it the check cannot read (a name, a function of the page's own, `site.trust` through a name of the page's own) is never named. `site.trust(fact)` draws a line that links the page its fact was read on, and the blank starter says so. In a space, `instafy bind init --starter <name>` now names the check as the next step: a check that passes posts the page's card, and one that fails names the card's command. `instafy preview open` of the same page of a site whose card is already showing, under another title, keeps the card's title instead of being refused, posts no second card, and answers "Its card is already in the chat.", with only what the site still needs (it doesn't answer, answers with an error, or Open can't start it again); another page of the same server is still refused. Pages made before keep their own copies of `app.js` and `site.js`.
