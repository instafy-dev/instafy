`instafy web search` without a search key no longer carries a key card (`offer`) or a line about one: its `no_provider` answer says only how to go on without a key. A turn asked for a score put the card it carried into its reply. A person who asks to set up search still gets the card, which Octo writes from the provider list's first key and its `key_request` words; those words now name the searches a day themselves.
