"New chat" makes a chat at once wherever it sits: the sidebar's button and the phone's More menu now do what the tab bar's "+" already did, with no "Public chat" / "Private chat" choice in between. A private chat starts from the composer's invite menu: in a chat that is not private, its "Private chat" section lists the space's teammates, and "Start" opens a private chat with that person (inside a private chat the section still adds people to it, as before). On Home, a chat's row never says "new" ("3 new of 3 updates" became "3 updates"): only Unread speaks for what is unread, and a chat already read in the chat itself since the last visit to Home was still counted as new there. Past rows in a row for chats that would read exactly the same (several untitled chats in one space with the same last update) show as one row standing for all their updates; work in progress keeps one row per chat. No package changes.
