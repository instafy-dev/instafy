While Octo works in Instafy's browser, the tabs it holds carry its name in the Shared Browser's tab picker and in the chat's page strip, and a compact **Octo is reading** row under the Personal and Shared Browser toolbars lists the pages it is reading by host and title. One **Take over** press in that row stops the agent and returns every tab to the person, the same as the toolbar's take-over; afterwards no tab carries the agent's name. Shared page lists may say who opened a tab (`openedBy`), and a Personal Browser host may list its tabs; both are optional, and older browsers show the tab the run was sent for. No package changes.
