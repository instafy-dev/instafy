`instafy mcp` serves your Instafy spaces to a coding agent on the same machine, such as Claude Code, over MCP on stdin and stdout: your teams and spaces, a space's conversations (list them, search the recent ones, search every message's text, read one, read around a message, start one), your agents, the space's agent settings, your agents' context notes, agent run status, runtime events and run results. The agent starts it, and `instafy mcp --help` describes it. Every tool call runs as you, on the session `instafy login` saved for the profile `INSTAFY_PROFILE` or the folder's `.instafy/space.json` selects, or else the default one, and is refused, naming the `instafy login` command that fixes it, when no session is saved. No tool takes a token or a server, and access tokens, server URLs and space ids set in the environment are ignored. A write always names its space, saving a context note replaces that agent's note for the same scope, and a write that ends without a definite answer says it may or may not have been made. Results are capped at about 36,000 characters and say what they left out: lists keep whole entries, a cut conversation page keeps a cursor that goes on from its last message, and an entry too long for one result is shortened. Up to four calls run at once, and each call stops 60 seconds after it arrives unless `INSTAFY_MCP_CALL_TIMEOUT_MS` sets another limit.
