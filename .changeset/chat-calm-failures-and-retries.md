A turn in chat now states its outcome once, in plain words. A failed turn has no "Run failed" beside its author and no activity line above its failure block ("Ran a command" read like a turn that went fine). The block is its one status, and its Details toggle says "Details ›" or "Hide details ⌄" and names what it opens. A turn that did not make the changes it was asked for reads "Octo didn't finish the changes." (with the agent's own name when the failure names one) instead of "The file changes didn't come through.", and the runtime's own sentence stays behind Details. No failure sentence says "Codex", "workspace" or "request" any more. An unclassified failure shows its own first line only when that line is plain; otherwise it says "Something went wrong, so this turn stopped." and keeps the raw text behind Details. The AI-connection lines read "couldn't answer this message" and "is busy right now". While Instafy tries a failed turn again by itself, the turn is one quiet "Trying again…" line, with no failure sentence, no red, no "Retried" and no buttons; a countdown before a rate-limited resend keeps its Cancel. Studio no longer sends a turn that did not make its changes again by itself: the runtime already gave it a second try, and each resend is a turn the person pays for, so "Try again" is theirs to press. The resent prompt is marked `retryAutomatic` and left out of the chat only when the failed turn is in view and the prompt repeats, from the same person, the words that turn answered; a message that merely carries the mark stays visible. A resend the controller refused before any job ran it no longer leaves the failed turn on "Trying again…". The failed attempt moves into the Details of the turn that replaced it, under "First try", so a retry that succeeds reads as a normal reply, and only a retry that fails too shows the failure block. A resend the person asks for with "Try again" stays as they sent it. The runtime's own retry status now says "Trying again" as well. A failure that names the routing preflight stays behind Details, and a browser turn whose machine went away reads "Personal Browser disconnected. Reconnect the desktop app, then try again." or "The Shared Browser closed when its machine stopped. Open it again, then try again." instead of asking to "retry this request". No package changes.
