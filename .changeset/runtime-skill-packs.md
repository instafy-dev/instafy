Every space now gets the skill packs installed with the runtime, without carrying their files in its history. `packages/runtime-agent/skill-packs.json` pins each pack's release archive (URL, sha256, commit and content hash); the first is `instafy-dev/maps-skill-pack` v0.1.0. `scripts/install-skill-packs.mjs` downloads and verifies them (sha256 before anything is read, links and paths outside the pack refused, the commit in the archive header, the content hash, at most 16 MB unpacked) for the runtime images (`/opt/instafy/skill-packs`, a build fails on any mismatch), for Desktop (beside the bundled runtime-agent, recorded and checked in its manifest) and for local development (`pnpm skill-packs:install`). Before each turn the runtime writes each pack's `SKILL.md` and, for a pack with a command, a small launcher into `.agents/skills/<pack>/`, lists them in the checkout's `info/exclude` so no save picks them up, and leaves edited, imported or tracked copies alone. No package changes.
