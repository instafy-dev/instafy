A browser turn uses only its own chat's page in Instafy's browser. The browser is shared by the space's chats, and a turn used to start on whatever tab was on screen, so a new chat's browser turn read the page another chat had left there (under routine browsing nothing asks before a page is read). Now each chat has a tab of its own: a chat's first browser turn gets a blank tab (the one tab of a browser that just started, or a new one Studio opens behind the tab on screen with `POST /browser/pages/new`, advertised as `controls.newPage`), and the turn's blank-page rule takes it to the task's site; later turns use the tab the chat's last browser turn used, or one the person chose in that chat; and the chat's Browser view shows that tab. When the browser cannot open the chat's tab it says so and sends nothing, rather than using another chat's page; an older browser without the route keeps the tab on screen. Studio no longer puts "Use the existing … page in the current shared browser session" in front of a message that mentions a page, and a card's continuation sends the card's task alone, without "Continue this browser task using the browser attached to this turn", which came back in replies as "the attached browser". A turn without browser tools never asks the person to enable, turn on or allow the browser or its tools: it ends with the browser card, and only the person's own Take over, stop or Deny keeps it from opening the browser again for a task. One rule for when the browser opens: on a space whose browser runs on its own machine, a card opens by itself whether that browser runs yet or not (the open starts it, also after it failed), unless someone else holds it, when the card keeps its "opens here by itself once it is free" button; a card no longer says "Studio opens the browser and continues this task there." and reads "Opening Instafy's browser…", then "Opened"; and Studio switches to the Browser view only on a press, otherwise staying in Chat with the reading line and the Browser tab's dot. The remote page goes back to the size of the person's view when they get to drive again, so it no longer stays phone-sized on a desktop after a check at phone size. No package changes.
