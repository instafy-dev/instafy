# Comparing items

Never prune: yes

For every reader and browser. Pages are found as "Finding a page" in `instafy-browser-automation` says.

## The items

- List the models a page you read names, its menu included, then open each one's own page. Never names from memory, never placeholders such as "candidate 1".
- Name: the exact model and generation its official page gives, else the page naming it. A product's official site is its maker's.

## Values

- A value is often on a tab or link of the item's own page (specs, warranty, support, FAQ): open the one for it before you call the value not found.
- Price: the maker's or a shop's own page. Missing or refused: try an allowed shop. Still none: "price unknown", with a page the person can send to Octo. Never remember or guess a price.
- A limit ("under €600"): an item with no price read this turn is listed as "price unknown", never as within it.

## Reviews

- Requested reviews: that many per exact model, from independent publishers, not its maker/shops or a sibling model.
- A review no page you read links to comes from a reviewer's own site: its home page, its links and its own search box.
- A review you have no address or link for is a value you didn't find, not a page to read: in Instafy's browser it goes in the missing line, never the unread line.
- Short: "<item>: 1 of 2 reviews found", in the reply and on the page, citing only those reviews.

## A value nobody found

- It reads `Unknown`, with why. One you looked for yourself says where you looked ("price not found on the shop's page"). One Octo's browser looked for and didn't find is said in the words its findings give ("I didn't find the warranty"), naming no page.
